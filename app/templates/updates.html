A release goes to one test controller first, then to the rest in batches. Each controller fetches the release itself from the official release branch, installs it, and proves it for 10 minutes; if it crash-loops it rolls itself back. A failed or rolled-back update, or a controller turning red after updating, halts the rollout and sends an alert, so a bad release reaches no one else.
